# bare-stow-host-kotlin

Host side of the [bare-stow](https://github.com/holepunchto/bare-stow) lifecycle for Kotlin. The Kotlin counterpart of [bare-stow-host](https://github.com/holepunchto/bare-stow-host): it multiplexes a control channel and a user data channel over a byte transport to a stowed bundle, and layers readiness, termination, and exit reporting on top. Harnesses generated by `bare-stow` use it to drive the bundles they boot.

## Installation

Add JitPack to the repositories of your project:

```groovy
dependencyResolutionManagement {
  repositories {
    maven { url "https://jitpack.io" }
  }
}
```

Then add the package to the dependencies of your module:

```groovy
dependencies {
  implementation "com.github.holepunchto.bare-stow-host-kotlin:bare-stow-host-kotlin:<tag>"
}
```

## Usage

```kotlin
import to.holepunch.bare.kit.IPC as WorkletIPC
import to.holepunch.bare.kit.Worklet
import to.holepunch.bare.stow.host.IPC
import to.holepunch.bare.stow.host.Transport

val worklet = Worklet(context)
val transport = WorkletIPC(worklet)

worklet.start("/app.bundle", bundle)

val ipc =
  IPC(
    object : Transport {
      override val data = transport.data

      override suspend fun write(data: ByteArray) = transport.write(data)
    },
    kill = { worklet.terminate() },
  )

scope.launch { ipc.exited(worklet.wait()) }

ipc.ready()
ipc.write("hello".encodeToByteArray())

val code = ipc.terminate()
```

Any `Flow` of `ByteArray` with a suspending `write()` can be wrapped by implementing `Transport`, such as the IPC of a worklet from [bare-kit-kotlin](https://github.com/holepunchto/bare-kit-kotlin).

## Protocol

Every frame is a 4-byte little-endian length followed by that many bytes: A 1-byte tag and the payload. The tag is `0x00` for a control frame, whose payload is a UTF-8 JSON object carrying its `type`, and `0x01` for a user data frame. See [bare-stow-protocol](https://github.com/holepunchto/bare-stow-protocol) for the control frames.
